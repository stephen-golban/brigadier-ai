# Other coding agents: resource complaints and transferable fixes

Checked 2026-09-11. Scope: Codex, Cursor, Gemini CLI, OpenCode. Preserve model choice, reasoning, context, concurrency, and CLI execution speed. No production edits, provider jobs, or local benchmarks. Reports establish observations on particular versions, not prevalence or a diagnosis of this Mac. “Merged” establishes an upstream code change; release inclusion is unverified unless stated.

## Concrete upstream fixes

**Gemini CLI: orphaned terminal process.** A January 4 report describes v0.15.4 on an Apple M4 continuing after terminal closure and consuming a core. [Issue #15874](https://github.com/google-gemini/gemini-cli/issues/15874). PR #16965, merged February 26, 2026, identifies closed-TTY reading as the spin source and adds signal-driven graceful shutdown, cleanup sequencing, and a shutdown race guard. It also adds a 5-second TTY fallback check; the PR still lists manual terminal-close testing as unchecked. Transfer the lifecycle fix, not that polling implementation: treat EOF/disconnect/owner exit as terminal events, close channels once, and reap owned children. [Merged PR and code](https://github.com/google-gemini/gemini-cli/pull/16965/files)

**OpenCode: empty-list render loop.** PR #6435, merged December 30, 2025, fixes reported 100% CPU and rapid memory growth when model filtering returns zero results. Its guard unmounts the scrollbox for an empty list, avoiding a zero-height renderer loop; verification covers empty results and restoring the list. No model capability is reduced. Brigadier should test empty, hidden, detached, and zero-sized transcript/list views for self-triggered render or resize loops. [Merged PR #6435](https://github.com/anomalyco/opencode/pull/6435)

## Reports with useful diagnostics

**Codex: client overhead while backend idle.** May 10 report #22053 names desktop 26.506.31421, macOS 26.4.1, M4/16 GB. The reporter sampled approximately 264–285% main-process CPU while app-server stayed around 0–1%; stacks involved stream callbacks and buffer copying. Logs showed repeated sidebar/status requests and Git probes. This is strong reporter-level evidence for investigating UI/IPC bookkeeping independently of AI execution; no maintainer-confirmed root cause or fix is established there. [Issue #22053](https://github.com/openai/codex/issues/22053)

**Codex: failed Git metadata requests repeat.** April 10 issue #17394 reports a profiled `stable-metadata` error loop in non-Git workspaces. Several commenters report CPU falling after repository initialization; others identify missing HEAD and ownership failures. It is now closed, but reports of recovery and persistence conflict and no fix release was verified. Brigadier should represent these as stable metadata states, cache them until filesystem changes, and avoid error→refresh→same-error feedback. Do not modify users' repositories as an optimization. [Issue and comments #17394](https://github.com/openai/codex/issues/17394)

**Cursor: watcher events can create scan storms.** On May 15, a Cursor 3.3.30/macOS reporter observed repeated `rg` waves after Yarn relinked dependencies, plus FSEvents dropped-event warnings. Search/watch exclusions and avoiding symlink traversal prevented recurrence in their repeated tests. May 19 support confirms ignore rules did not cover every retrieval scan path and endorses that mitigation; no shipped fix is established. Transfer consistent scan exclusions, cycle detection, shared scan results, and coalesced resynchronization. Preserve on-demand agent access to files; excluding generated artifacts from automatic indexing must not silently deny tool access. [Report and support response](https://forum.cursor.com/t/retrieval-extension-spawns-runaway-rg-workers-after-yarn-node-modules-relink/160696)

**OpenCode: repeated copying during streaming.** May 31 report #30067 identifies text/reasoning accumulation and repeated materialization in v1.15.11/1.15.12. The author reports reduced per-step latency with patches, but the issue remains open and those results are not independently reproduced. Audit for cumulative transcript reserialization and string copying; store append-only chunks, send deltas, and parse/render only changed content. [Issue #30067](https://github.com/anomalyco/opencode/issues/30067)

## Priorities for Brigadier

Replace idle refresh polling with mutation events and native watches; coalesce duplicate invalidations without slowing CLI output; use ordered IPC channels for streams. Fix persistent error/retry loops, bound render work to visible changes, avoid cumulative transcript copies, and guarantee lifecycle cleanup. Watchers alone are insufficient if every event starts another full scan.

Validate with idle/no-Git/empty-view fixtures, dependency-relink event storms, long transcript replay, terminal/owner exit, and unchanged multi-agent workloads. Track wrapper CPU, allocations, IPC bytes, wakeups, UI latency, and task completion time separately. These fixes target wasted work; they do not guarantee that legitimate concurrent builds/tests will run cool.
