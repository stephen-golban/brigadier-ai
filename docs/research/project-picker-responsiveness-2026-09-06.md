# Project picker responsiveness

Checked 2026-09-06: local JavaScript and Rust `tauri-plugin-dialog` **2.7.3**, plus official Tauri documentation. Research only; no picker was opened and no latency was measured.

**There is no supported native directory-picker preload/warmup API in the inspected version.** The JavaScript exports are `open`, `save`, `message`, `ask`, and `confirm`; `open()` immediately invokes the native dialog command. Documented options include directory selection and an initial path, but no hidden/preload mode. [Official JavaScript API](https://v2.tauri.app/reference/javascript/dialog/), [versioned JS source](https://github.com/tauri-apps/plugins-workspace/blob/6aa2854f314481a459be1189b02c65a2450789ab/plugins/dialog/guest-js/index.ts).

The Rust command creates a builder, applies options, then calls the folder picker. Builder construction only stores configuration fields. The desktop folder-pick implementation schedules creation of the real `rfd::AsyncFileDialog` on the main thread. Constructing a builder is therefore not evidence of warming the OS chooser, and calling `open()` invisibly is not a supported preparation path. The source commit is recorded in the installed crate's `.cargo_vcs_info.json`. [Command](https://github.com/tauri-apps/plugins-workspace/blob/6aa2854f314481a459be1189b02c65a2450789ab/plugins/dialog/src/commands.rs#L122), [builder](https://github.com/tauri-apps/plugins-workspace/blob/6aa2854f314481a459be1189b02c65a2450789ab/plugins/dialog/src/lib.rs#L416), [desktop dispatch](https://github.com/tauri-apps/plugins-workspace/blob/6aa2854f314481a459be1189b02c65a2450789ab/plugins/dialog/src/desktop.rs#L172).

Brigadier already imports the dialog module statically in `src/bridge.ts:14` and registers the Rust plugin during builder setup in `src-tauri/src/lib.rs:126`. There is no separate dialog-module lazy import here to remove.

Recommended implementation boundary: make the Create project modal's first render independent of asynchronous folder work; eagerly include its UI, prepare recent/default paths and existing-project metadata, and let the name field work immediately. Request the native picker from Browse and preserve form state through cancel/error. A default folder can reduce navigation, but no checked API promises a faster native first paint. Show only truthful pending feedback; do not label background configuration work as an OS picker warming up. Benchmark cold and subsequent Browse invocations in the packaged app before assigning a latency target.
