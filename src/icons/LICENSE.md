# Icon set licence

Every `.tsx` file in this directory is generated by `scripts/vendor-icons.mjs` from
[`@openai/apps-sdk-ui`](https://github.com/openai/apps-sdk-ui) **0.2.2**, the Apps SDK design
system published by OpenAI. The SVG markup is theirs, copied element for element; only the file
header, the `SVGProps<SVGSVGElement>` annotation and the `data-icon` attribute are ours.

Vendored rather than imported because the package exposes its 745 icons behind one barrel whose
relative re-exports carry no file extension, which Node's ESM resolver rejects (upstream issue #39)
— see `docs/research/apps-sdk-ui-icons.md` §8. The icons themselves import nothing but
`react/jsx-runtime`, so copying them is lossless.
